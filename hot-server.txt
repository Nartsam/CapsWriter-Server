# 服务端热词：识别时提高这些词被识别出来的概率，不是替换
#
# 每行一个词，# 开头为注释。可以写成「词 | 加分」单独指定加分，不写则用 config_server.py 的 hotword_bonus（默认 4）。
# 加分 b 相当于告诉模型「这个词比你以为的常见 e^b 倍」：4 约 55 倍，6 约 400 倍；超过 8 容易把相近的词也改成热词。
# 只有整个词都写出来时才加分，所以不会影响只有一两个字同音的其他词。
# 保存后下一次识别即生效，不用重启服务端。
#
# 适合：模型认得、但常写成同音/近音词的词（英文术语、人名）。
# 不适合：模型几乎不认识的词（例如「立绘」总被写成「例会」，差距大到加分翻不过来，请用客户端 hot-rule.txt 按语境替换）；
#         单个汉字（没有后文可以验证，会把所有同音字都往这个字上拉，请写成常用的完整词，如「台灯」「灯光」）。
